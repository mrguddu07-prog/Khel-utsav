# 🏆 Khel Utsav 2025–26

Official sports tournament registration website for  
**Dev Bhoomi Uttarakhand University, Dehradun**

## 🌐 Live Demo
> Coming soon

## ✨ Features
- 🏏 Online registration for 9 sports events
- 📧 Automatic confirmation emails via Nodemailer
- 🗄️ MongoDB database for storing registrations
- 👨‍💼 Admin dashboard with live registration stats
- 📱 Fully responsive mobile-friendly design
- 🔐 Secure admin login panel
- 🎨 Animated hero section and sport cards

## ⚙️ Local Setup

1. Clone the repo

       git clone https://github.com/mrguddu07-prog/Khel-utsav.git

2. Install dependencies

       npm install

3. Create a `.env` file in root folder

       MONGO_URI=your_mongodb_uri
       MAIL_USER=your_gmail
       MAIL_PASS=your_app_password
       ADMIN_MAIL=admin_email
       PORT=3000

4. Start the server

       node server.js

5. Open browser and go to `http://localhost:3000`
